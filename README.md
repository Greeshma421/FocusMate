FocusMate — Phase 1 (Backend scaffold)

This repository contains the Phase 1 scaffold for FocusMate: a FastAPI backend using async SQLAlchemy and PostgreSQL.

Phase 1 includes:
- FastAPI app skeleton
- Async SQLAlchemy engine and session
- Basic User model and Pydantic schemas
- Simple register/login endpoints (bcrypt + JWT)
- Alembic skeleton for migrations
- Docker Compose to run Postgres and Redis locally
- Basic health endpoint and a test

See apps/api/README.md for backend setup instructions.
